## Findings

### R-02 — Copywriting (Hard Gate, HIGH)

1. **i18n/strings.ts — 76 em dash (`—`) characters in user-facing copy across EN/FA/DE** (e.g. `"Ratings unlock from kickoff — pick a match to follow first."`). R-02 forbids the em dash in any UI text. Fix: replace every em dash in `strings.ts` with a comma, period, colon, or parentheses and regenerate the locale files.

### R-37 — Design Direction Required (Hard Gate, HIGH)

2. **Repo root — no `DESIGN.md`.** Direction exists only as `design-system.md`, and `AGENTS.md`/`CLAUDE.md` does not route the agent to it. Antislop treats this as "draft without direction"; the dials are undeclared. Fix: create a `DESIGN.md` at the repo root (recommended content below) and add a one-line routing note in `AGENTS.md`/`CLAUDE.md`: "For UI work, read `DESIGN.md` for direction, then `antislop.md` as the filter."

3. **Dials undeclared — ENERGY / RHYTHM / MOTION are not stated anywhere.** The app ships a rich motion set (goal flash, score odometer, timeline entrance, live glow, shimmer) and varied section composition, but no dial values are declared, so R-19/R-05 cannot be verified against intent. Fix: declare `Dial: ENERGY 2 / RHYTHM 2 / MOTION 2` in `DESIGN.md` and confirm every screen holds to it.

### R-19 — Animations (Purpose-Gate, MEDIUM)

4. **Motion dial undeclared (see #3).** Without a declared MOTION dial, the infinite loops (`live-dot` 1.6s ring, `live-glow` 2.4s pulse, `shimmer` 1.4s sweep) cannot be checked against R-19's "motion must match the declared dial." Fix: declare the dial and verify each infinite animation marks a real state (live/loading) and stops under `prefers-reduced-motion` (already implemented — keep it).

### R-21 — Dark Mode (Quality Lock, MEDIUM)

5. **App shell — dark-only, no light/dark toggle and no documented reason in a `DESIGN.md`.** `color-scheme: dark` is hard-coded in `index.html` and `tokens.css`; `design-system.md` says "dark-first; light mode is a later phase, not v1." R-21 requires choosing the theme from brand identity or building a working toggle; a content-first product with no documented reason reads as "dark because it looks tech." Fix: either document the dark-first decision as brand identity in `DESIGN.md` ("Floodlit Night" stadium aesthetic) or implement a working light/dark toggle verified in both modes (R-34).

### R-29 — Color Palette (Quality Lock, LOW)

6. **Design tokens — 5 named accents (volt, live, gold, danger, pitch) exceed R-29's 2-3 core + 1 accent cap.** Each has a documented semantic role, but the active accent count is 5. Fix: collapse to 2-3 core + 1 accent in `DESIGN.md`, or explicitly list the five as distinct semantic states (live/danger/pitch) so the cap is waived by documented role.

### R-01 — Color & Gradients (Purpose-Gate, LOW)

7. **Volt (teal) applied to ~100 call sites** (`text-volt`, `bg-volt`, `border-volt` across buttons, chips, links, active tabs, league chips). R-01/R-13 dose: the accent must land at the key moment only; used everywhere it stops being an accent. Fix: reserve volt for the single primary action per screen; secondary affordances use `ink-2`/`ink-3` and neutral borders.

### R-39 — Accessible Semantics & Interaction Affordances (Hard Gate, MEDIUM)

8. **Base CSS layer — no global `cursor: pointer` for enabled interactive elements.** Only 3 `cursor-pointer` occurrences exist in `src`; `<button>`/`<a>` rely on the browser default (arrow), so controls do not advertise clickability. R-39 requires `cursor: pointer` set once in the base CSS layer. Fix: add `button, a[href], summary, [role="button"], [role="tab"], [role="switch"], label[for] { cursor: pointer; }` (and `:disabled { cursor: not-allowed; }`) to `index.css` `@layer base`.

### R-40 — Performance Mechanisms (Quality Lock, MEDIUM)

9. **Images without intrinsic dimensions — crests (`ui.tsx` TeamBadge), news thumbnails (`NewsCard.tsx`), player avatars (`ui.tsx` PlayerAvatar) ship `<img loading="lazy">` with no `width`/`height` or `aspect-ratio`.** R-40 requires dimensions to prevent CLS. Fix: add `width`/`height` (or `aspect-ratio`) to each `<img>`; crests are square (24/36/48/64px), so set matching attributes.

10. **No `fetchpriority="high"` on any above-the-fold image.** R-40 requires the hero/largest above-the-fold image to be an `<img>` in HTML with `fetchpriority="high"`, never lazy. The Login mark (`/vkick-mark.svg`) and the boot splash are the only above-the-fold images and neither sets it. Fix: add `fetchpriority="high"` (and keep `loading="eager"` default) to the Login mark and boot splash img.

11. **Render-blocking third-party CSS in `<head>` — Google Fonts fallback stylesheet** (`fonts.googleapis.com` for Archivo + Vazirmatn) is a synchronous `<link rel="stylesheet">` in `index.html`. R-40 forbids render-blocking third-party resources in `<head>`. Fix: load the fallback with `media="print" onload="this.media='all'"` or move it behind the self-hosted fontsource imports only.

# DESIGN.md — Vkick

## Identity
Name: Vkick (VerdiKick). Concept: "Floodlit Night" — a deep green-black pitch under stadium floodlights.
Product: Persian/English football scores & matchday app (Telegram Mini App + web). Audience: Iranian and international football fans, mobile-first.
Personality: broadcast energy, precise, data-dense but calm. Never generic "tech dark".

## Direction routing
For UI work, read this file for direction, then antislop.md as the filter.

## Dials
Dial: ENERGY 2 / RHYTHM 2 / MOTION 2
(ENERGY 2 = Stripe/Vercel level; RHYTHM 2 = consistent with a few breaks; MOTION 2 = scroll-reveal + transitions, with signature moments.)

## Palette (strict semantics — one meaning per color)
- Base surfaces (dark-first; light mode is a later phase): --bg-base #081613, --bg-surface #0E2520, --bg-elevated #122C25, --border-subtle #2A4D44.
- Text: --text-primary #EDF7F3, --text-secondary #93AEA6, --text-muted #7B958C (≥4.5:1 on all surfaces).
- Accents: --volt #1FBFA0 (broadcast teal: primary actions, your predictions, CTAs, goal flashes); --live #FF5A4D (LIVE state only); --gold #F2B705 (evaluative amber: ratings, points, bonus); --danger #FF4D5E (errors, wrong predictions, red cards); --pitch #23A066 (turf green, tinted, never dominant).
- Rules: volt is never a background wash; points/ratings are always amber even in teal contexts; a team's color tints only its own badge/discs/bars.

## Typography
- Display/numbers: Archivo (800–900), tabular-nums, negative tracking in Latin only.
- UI/body/Persian: Vazirmatn (400, 700), full Persian + Latin.
- Scale: display 48px, title 22px, body 16px, meta 14px, micro-label 12px (Persian floor — never below 12px).
- Micro-label is one `.label` class: 12px/700; uppercase + 0.04em tracking in Latin, plain in Persian.

## Theme
Dark-first ("Floodlit Night"). Reason: stadium floodlight aesthetic for a live-match product. Light mode is a later phase, not v1. If a toggle is added later, both modes must pass R-34.

## Components
- Cards: 14px radius, 1px --border-subtle, --bg-surface, no heavy shadows (elevate via --bg-elevated).
- Buttons: volt fill + black text + pill (999px) for primary; ghost 1px border for secondary.
- Club identity is the crest: square footprint at 24/36/48/64px; fallback is abbreviation on a club-coloured rounded tile. Crests never stretched/clipped/recoloured.
- Icons: one set in src/components/icons.tsx, 1.8 stroke on 24 viewBox, currentColor. No generic AI glyphs.
- Touch targets ≥44px.

## Motion
- Durations: --t-fast 150ms, --t-std 250ms, --t-slow 450ms. Easings: exits/standard cubic-bezier(0.22,1,0.36,1); playful overshoot cubic-bezier(0.34,1.56,0.64,1). Only transform + opacity animate. Respect prefers-reduced-motion.
- Signature animations: goal flash (volt sweep + confetti), score odometer, timeline entrance (staggered 40ms), pin drop, live dot pulse, rating snap, deadline heat, skeleton shimmer, live card halo, toast drop, pull ring.

## Texture
- Pitch motif: faint pitch-line watermark (center circle/grid at 4% opacity) behind prediction cards — brand texture, quiet.

## Platform
- Telegram Mini App: header color = --bg-base, haptic feedback on pin drop/rating.
- Safe areas + webview quirks; test on low-end Android.
- Web fallback: same tokens, same components.
